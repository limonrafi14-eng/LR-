Limon Refrigerator Android APK Project
--------------------------------------
এটি তোমার offline মাসিক হিসাবের Android project.
APK বানাতে Android Studio-তে project folder খুলে:
Build > Build APK(s)
তারপর app/build/outputs/apk/debug/app-debug.apk ফাইলটি ফোনে Install করতে হবে।

অ্যাপটি internet ছাড়া কাজ করবে এবং হিসাব browser localStorage-এ সংরক্ষণ করবে।
